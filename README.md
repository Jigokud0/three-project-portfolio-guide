# Как собрать портфолио из трёх работ

У портфолио интерьерного фотографа три потенциальных читателя: дизайнер, риелтор и владелец небольшого кафе. Каждому нужен свой ответ, поэтому начните с трёх работ, которые показывают разные задачи.

## Три карточки вместо случайной галереи

Для дизайнера покажите квартиру и объясните, как передали цвет материалов. Для риелтора — компактную студию и кадры, которые помогают понять планировку. Для кафе — общий зал и свет у столиков. Добавьте к каждой карточке задачу, одно решение и подтверждённый результат. Используйте свои работы и разрешённые фотографии.

## Как выбрать главный пример

Поставьте первым кейс по типу заказов, которые хотите получать чаще. Проверьте страницу на телефоне: подпись должна быть видна рядом с фотографией, а контакт — доступен из любой карточки.
